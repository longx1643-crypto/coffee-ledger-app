កម្មវិធីសៀវភៅចំណូលចំណាយហាងកាហ្វេ — PWA starter

ឯកសារនេះត្រូវបង្ហោះលើ hosting ដែលប្រើ HTTPS មុនពេលអាចដំឡើងជា PWA ឬបង្កើត Android APK តាម PWABuilder។

ឯកសារសំខាន់៖
- index.html: កម្មវិធីដើមរបស់អ្នក
- manifest.webmanifest: ព័ត៌មានសម្រាប់ដំឡើងជាកម្មវិធី
- service-worker.js: cache ឯកសារកម្មវិធីដើម្បីគាំទ្រការប្រើ offline
- icon.svg: រូបតំណាងកម្មវិធី

ចំណាំ៖ ទិន្នន័យកត់ត្រារក្សាទុកក្នុង browser storage របស់ឧបករណ៍នីមួយៗ។ វាមិនធ្វើសមកាលកម្មរវាងទូរស័ព្ទច្រើនគ្រឿងទេ។ សូមសាកល្បង និងនាំចេញ CSV ជាប្រចាំ។
